# SDVC 웹서비스 — 제품 개요

> 작성일: 2026-09-07 · 상태: **기획 착수 (명세 이전 단계)**

## 1. 이름과 정의

**SDVC = Structured Document & Vibe Coding**
> **구조화된 문서가 AI 코딩을 이끈다.**

기존 **AI-VC(AI 바이브코딩)** 방법론 v1.2.0을 그대로 계승하되,
"교육용 개인 스킬"에서 **유료 웹서비스 제품**으로 제품화하기 위해 붙인 새 이름이다.

| 구분 | AI-VC (기존) | SDVC (신규) |
|---|---|---|
| 성격 | Claude Code 개인 스킬 / 교재 부속물 | 유료 웹서비스 제품 |
| 배포 | `install.bat`, GitHub 플러그인 | 웹 로그인 + 결제 + 서버 API |
| 스킬 이름 | `vibecoding-guide` | `sdvc-guide` |
| 트리거 | "AI바이브코딩 작동" | **"SDVC 최신버전 작동"** |
| 방법론 | 5블록 7단계 + 승인 게이트 + TDD + progress.md | **동일 (변경 없음)** |

기존 AI-VC 자산은 `..\` (AI Vibecoding 루트)에 **그대로 보존**되어 있다. SDVC는 그 완전 복제본 위에서 출발한다.

## 2. 제품이 파는 것

방법론 자체(5블록 7단계·승인 게이트·증거 기반 보고·progress.md 인계)를
**브라우저에서, 설치 없이, 초보자가 따라할 수 있게** 제공하는 것.

- 사용자는 로그인만 하면 됨 (Claude Code 설치·API 키 발급 불필요)
- 서버가 Claude Agent SDK로 방법론을 실행하고 산출물(spec/plan/tasks/코드)을 돌려줌
- 결제 상태·트라이얼 기간을 서버가 판정 → 통과 시에만 Anthropic API 호출

## 3. 현재까지 확정된 사전조사 결론

상세: [`20260907_웹서비스_제품화_논의요약.md`](20260907_웹서비스_제품화_논의요약.md)

| 항목 | 결론 |
|---|---|
| 기술적 재현 가능성 | **가능** — Claude Agent SDK(Python/TS) 또는 CLI headless(`claude -p`) |
| 인증/과금 | 서비스 제공 시 **API 키 기반 종량제** 사용 (구독 한도 전가는 사전승인 없이 불가) |
| 브랜딩 | "Claude Code" 명칭·모방 금지. "SDVC, Powered by Claude" 형태는 허용 |
| 유료 회원 제한 | 가능 — 계정 자체가 라이선스 (로그인 + 결제사 연동 + 서버 판정) |
| 복제 방지 | 서버 측 프롬프트·워크플로 로직은 브라우저로 전송되지 않으므로 사실상 안전. UI/아이디어 모방은 기술로 못 막음 |
| 체험 기간 | 가능 — 서버 DB 가입일 기준 판정 (클라이언트 판정 금지). Stripe `trial_period_days` 등 활용 |

## 4. 미결정 사항 (다음 세션에서 SDVC 절차로 결정)

- [ ] 백엔드 언어: Python(claude-agent-sdk) vs TypeScript(@anthropic-ai/claude-agent-sdk)
- [ ] 스택: Next.js + Supabase + Stripe(또는 토스페이먼츠) 조합 확정
- [ ] `/speckit.*` 커스텀 커맨드를 플러그인/스킬로 패키징해 SDK에서 실행 가능한지 실증
- [ ] 서버 API 키 보관 방식 + 사용자별 사용량 상한/모니터링 설계
- [ ] 요금제(무료 체험 N일 / 월 구독가 / 토큰 상한) 수치 확정
- [ ] EULA·환불정책·개인정보처리방침 — **법률 검토 필요** (기술 결정 아님)

## 5. 작업 방식

이 폴더에서의 개발은 **SDVC 방법론 자신을 적용**해서 진행한다.
즉 `SDVC 최신버전 작동` → 헌장 → 명세 → 명확화 → 계획(승인) → 작업분해(승인) → 분석 → TDD 구현.

산출물 위치:
```
10_SDVC_웹서비스/
├── _제품_개요.md                      ← 이 문서
├── 20260907_웹서비스_제품화_논의요약.md   사전조사 결론
└── (앞으로) constitution.md / spec.md / plan.md / tasks.md / app/
```
진행 상황은 `..\docs\progress.md` 에 기록한다.
