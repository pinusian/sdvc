# _작업기억 (SDVC 도메인)

프로젝트별 하위 폴더에 3종 파일을 둔다.

- `plan.md` — 전체 작업 계획(무엇을, 어떻게, 언제까지)
- `context.md` — 주요 결정 사항과 그 이유
- `checklist.md` — 단계별 완료 체크리스트

## 현재 프로젝트

| 폴더 | 상태 |
|---|---|
| `독서활동/` | 산출물 아카이브 완료. 코드(reading-activity-example) + 문서 백업됨 |
| `AI 코드학습지원 서비스/` | 코드 위치 확인(`C:\Users\USER\AI_Code_Study`) + git 번들 백업 완료 |
| `AI-VC/` | (승계) 방법론 스킬. vibecoding-guide/starter 번들 + 스킬 원본 스냅샷 |
| `SDVC/` | **★ 현재 주 트랙.** SDVC 플랫폼 + 유료 웹서비스 제품화 |

새 프로젝트 시작 시 이 폴더에 `<프로젝트명>/` 을 만들고 3종 파일을 생성한다.
