# plan.md — SDVC 플랫폼

## 목표
AI-VC 방법론을 계승한 **SDVC 유료 웹서비스**를 만든다.
브라우저 로그인만으로, 설치·API키 없이, 초보자가 5블록 7단계 절차를 밟아 앱을 완성하게 한다.

## 단계

### 0단계 — 플랫폼 셋업 ✅ (2026-09-07 완료)
- AI Vibecoding 전체 복제 → `SDVC\`
- 스킬 리브랜딩 `sdvc-guide` v2.0.0 + 트리거 "SDVC 최신버전 작동"
- GitHub 플러그인 구조 + 저장소 업로드
- `10_SDVC_웹서비스\` 제품 트랙 개설

### 1단계 — 제품 정의 (다음)
`SDVC 최신버전 작동` → 블록1(헌장+명세) → 블록2(명확화)
- 백엔드 언어·스택 확정
- MVP 범위 확정 (권장: "로그인 → 트라이얼 판정 → 명세 생성 1회전")
- 요금제 골격 확정

### 2단계 — 설계·작업분해
블록3(계획★승인) → 블록4(작업분해★승인)
- Agent SDK 연동 방식, API 키 보관/사용량 상한 설계
- 결제·트라이얼 데이터 모델

### 3단계 — 구현
블록5(분석 + TDD 구현). RED→GREEN→REFACTOR, 단계별 커밋, 실행 증거 첨부.

### 4단계 — 출시 준비
- 사용량 모니터링·비용 상한
- EULA/환불정책/개인정보처리방침 (법률 검토)
- Anthropic 정책 재확인 (구독-기반 SDK 사용 정책 보류 건)
