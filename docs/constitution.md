# constitution.md — SDVC 웹서비스 프로젝트 헌장

> 작성일: 2026-09-07 · 이 프로젝트 전체에서 예외 없이 지키는 규칙

## 1. TDD 필수
테스트를 먼저 쓰고(RED), 통과시키는 최소 코드를 짜고(GREEN), 그다음 정리한다(REFACTOR).
테스트 없이 "완성"이라고 선언하지 않는다.

## 2. 보안 규칙
- API 키·비밀번호·결제 관련 시크릿은 **AI가 절대 값을 채우지 않는다.** 빈 `.env.example` 틀만 만들고 사용자가 직접 입력한다.
- 시크릿은 `.gitignore` 로 커밋에서 제외한다 (이미 `SDVC/.gitignore`에 `.env` 반영됨).
- 회원 개인정보(이메일 등 최소 수집 항목)는 저장 시 암호화 또는 해시 처리한다.

## 3. 기록 의무
- 모든 주요 결정은 `spec.md` / `plan.md` / `tasks.md` 와 커밋 메시지에 남긴다.
- 슬라이스(기능) 하나가 끝날 때마다 `docs/task-reports/` 에 완료 보고서를 작성한다.
- 세션 종료 시 `docs/progress.md` 를 갱신한다.

## 4. 커밋 컨벤션
`{type}: {제목} - {단계}` 형식.
예: `test: 로그인 - RED (T003)`, `feat: 로그인 - GREEN (T004)`, `refactor: 로그인 - REFACTOR (T005)`
type은 `feat` / `fix` / `test` / `refactor` / `docs` / `chore` 중 하나.

## 5. 완료 보고 규칙
실제로 실행하지 않은 것을 "통과했다", "동작한다"라고 말하지 않는다. 완료 보고에는 반드시 실행한 명령과 그 출력을 함께 제시한다.
