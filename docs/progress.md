- **트리거 사용법**: 이 트랙을 이어갈 때는 `SDVC 최신버전 작동`보다 `SDVC서버 구축`을 우선 사용(최초 시작도 재개도 동일 문구). 중단할 때는 `작업 휴식`이라고 하면 이 형식으로 자동 저장된다.
- **WBS docx 재생성**: `10_SDVC_웹서비스/_wbs_docx생성.js`가 생성 스크립트다. md와 docx를 함께 출력하므로 내용 수정 시 이 스크립트를 고쳐 재실행할 것(둘을 따로 고치면 어긋난다). 실행: `npm install docx` 후 `node _wbs_docx생성.js <출력.docx> <출력.md>`. 스크래치패드는 세션 간 초기화되므로 npm install을 매번 다시 해야 한다.
- **WBS 문서 이력**: v1.0(20260907, 53세션)은 참고용으로 남겨두고, **현행은 v2.0(20260908, 75.5세션)**이다. 세션 수가 늘어난 것은 범위가 커졌기 때문이지 추정이 바뀐 게 아니다.
