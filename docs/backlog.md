# 상시 접수함 (Backlog)

> 쓰다가 발견한 문제와 개선 요청을 **발견 즉시** 여기에 등록한다.
> 매번 계획을 새로 짜지 않기 위한 장치다 — 모아 두었다가 슬라이스 단위로 처리한다.

## 처리 규칙

| 영향도 | 뜻 | 처리 |
|---|---|---|
| **치명** | 이미 파는 기능이 동작하지 않는다 | 진행 중인 작업을 멈추고 **즉시** 끼워넣는다 |
| **높음** | 쓸 수는 있으나 사용자가 곧 막힌다 | 다음 슬라이스에 넣는다 |
| **보통** | 불편하지만 우회할 수 있다 | 모아서 다듬기 슬라이스로 |
| **낮음** | 있으면 좋다 | 여유 있을 때 |

등록할 때는 **증상 · 재현 방법 · 영향도**를 적는다. 재현 방법이 없으면 고쳤는지 확인할 수 없다(SC-008).
처리되면 `상태`를 바꾸고 관련 작업 ID와 커밋을 남긴다. 지우지 않는다 — 같은 문제가 다시 나올 때의 단서다.
