## 복원 방법

```bash
# 1) 번들에서 저장소 복원
git clone AI_Code_Study.bundle AI_Code_Study
cd AI_Code_Study
git remote set-url origin https://github.com/pinusian/ai-code-learning-platform.git

# 2) (선택) 미커밋 변경분 다시 적용
git apply ../_uncommitted_changes.patch

# 3) 백엔드
python -m venv backend/.venv
backend/.venv/Scripts/activate      # Windows
pip install -r requirements.txt
cp .env.example .env                # ANTHROPIC_API_KEY 직접 입력

# 4) 프런트엔드
cd webapp && npm install && cd ..
cd webapp-reading && npm install && cd ..

# 5) 실행
start-servers.bat                   # 또는 docs/run-guide.md 참고
```
