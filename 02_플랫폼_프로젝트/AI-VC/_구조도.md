## 복원 방법

```bash
# 저장소 복원 (번들에서)
git clone vibecoding-guide.bundle vibecoding-guide
cd vibecoding-guide && git remote set-url origin https://github.com/pinusian/vibecoding-guide.git && cd ..
git clone vibecoding-starter.bundle vibecoding-starter
cd vibecoding-starter && git remote set-url origin https://github.com/pinusian/vibecoding-starter.git && cd ..

# 개인 스킬로 재설치
skill_최신본\install.bat      # → ~\.claude\skills\vibecoding-guide\
```

## 갱신 방법 (스킬 수정 후)

1. 원본 `AI Vibecoding\skill\vibecoding-guide\` 수정 + `VERSION` 올림
2. 두 저장소(`vibecoding-guide`, `vibecoding-starter`)의 스킬 파일에도 반영 후 커밋·push
3. 이 폴더에서 번들 재생성:
   `git -C <repo> bundle create "<이폴더>\vibecoding-guide.bundle" --all`
4. `skill_최신본\` 스냅샷 갱신
