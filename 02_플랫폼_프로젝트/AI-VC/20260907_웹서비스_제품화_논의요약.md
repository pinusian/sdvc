**작성일**: 2026-09-07
**용도**: Claude.ai 채팅에서의 논의를 Claude Code 프로젝트 컨텍스트로 이관
**배경**: AI-VC(바이브코딩 방법론) 도서 프로젝트를 별도 웹서비스로 제품화하는 방안 검토

## 1. 핵심 질문과 결론

### Q1. Claude Code 앱의 바이브코딩을 별도 웹서비스 + API로 재현할 수 있는가?

**결론: 가능함.** 단, Claude Code 앱 자체를 원격 호출하는 게 아니라 아래 두 경로 중 하나로 "재구현"하는 방식.

| 방식 | 설명 |
|---|---|
| Claude Agent SDK | Python/TypeScript 라이브러리. Claude Code와 동일한 도구(파일 읽기/쓰기/편집, bash 실행, 웹검색), 에이전트 루프, 컨텍스트 관리, 훅(hooks), 서브에이전트, MCP 연동, 권한제어, 세션 유지, 스킬/커맨드/메모리, 플러그인을 서버 코드에서 그대로 사용 가능 |
| CLI headless 모드 | `claude -p --output-format json`(또는 `stream-json`)으로 서버가 Claude Code CLI를 서브프로세스로 실행 |

**중요 제약**:
- Anthropic 정책상 제3자 제품이 claude.ai 로그인이나 구독 기반 사용한도를 그대로 최종 사용자에게 제공하는 것은 사전 승인 없이 불가 → **API 키 기반 종량제 인증**을 사용해야 함
- 브랜딩 제약: "Claude Code"라는 명칭이나 이를 흉내 낸 ASCII 아트 사용 금지. 자체 브랜딩 유지 필요. "AI-VC, Powered by Claude" 형태는 허용
- Agent SDK 사용은 Anthropic 상업이용약관 적용 (고객에게 제공하는 서비스에 활용 시에도 동일 적용)
- `/speckit.specify` 같은 커스텀 슬래시 커맨드는 커맨드/스킬/플러그인으로 패키징되어 있다면 SDK에서도 동일하게 인식·실행 가능 → "명세 만들기" 버튼 → 서버가 SDK로 해당 커맨드 실행 → 결과 반환 구조가 이론적으로 가능 (단, Spec Kit 쪽 실제 구현 구조는 별도 확인 필요)

참고: https://code.claude.com/docs/en/agent-sdk/overview / https://code.claude.com/docs/en/headless

### Q2. Agent SDK 과금 체계와 신청 방법

**신청 경로 2가지**

| 구분 | A. API 키 방식 (권장, 프로덕션용) | B. 기존 구독 사용 (Pro/Max/Team/Enterprise) |
|---|---|---|
| 신청처 | console.anthropic.com | 별도 신청 없이 기존 계정 로그인 |
| 인증 | `ANTHROPIC_API_KEY` 환경변수 | Claude Code CLI 로그인 시 OAuth 토큰 |
| 과금 | 토큰 종량제(postpaid) | 구독 사용한도 내 (아래 참고) |

**신청 절차 (A. API 키 방식)**
1. console.anthropic.com 계정 생성/로그인
2. 결제수단 등록 (신규 가입 시 소액 무료 크레딧 제공)
3. API Keys 메뉴에서 키 생성 → 즉시 저장
4. `ANTHROPIC_API_KEY` 환경변수 등록
5. SDK 설치: Python `pip install claude-agent-sdk` (3.10+) / TS `npm install @anthropic-ai/claude-agent-sdk`

**모델별 토큰 단가 (2026-09 기준)**

| 모델 | 입력 | 출력 | 비고 |
|---|---|---|---|
| Claude Haiku 4.5 | $1/MTok | $5/MTok | 단순 작업용 |
| Claude Sonnet 5 | $2/MTok | $10/MTok | 코딩·에이전트 범용, 도입가가 정식가로 확정됨 |
| Claude Opus 5 | $5/MTok | $25/MTok | 복잡한 추론·코딩 |
| Claude Fable 5.1 | $10/MTok | $50/MTok | 장기 실행 에이전트 특화 |

- 프롬프트 캐싱: 재사용 시 기본 입력가의 0.1배(90% 할인)
- 배치 API: 실시간성 불필요 시 입출력 50% 할인
- 계산 예시(Opus 5, 1시간 코딩 세션, 입력 5만/출력 1.5만 토큰): 약 $0.625

**⚠️ 확인 필요 — 구독(B) 방식 정책 변동 이력**
- 2026-06-15부로 Agent SDK/`claude -p`/서드파티 앱 사용량을 구독 한도와 분리된 별도 월간 크레딧(Pro $20, Max20x $200 등)으로 운영한다고 발표
- 같은 날 이 변경이 **보류(pause)**됨 → 현재는 구독 방식 사용 시 기존 인터랙티브 사용량과 **동일한 한도를 공유**
- 정책이 재변경될 수 있으므로 실제 서비스 착수 직전 https://support.claude.com/en/articles/15036540 재확인 필요
- Anthropic은 팀 단위 상시 프로덕션 자동화에는 API 키 기반 종량제를 명시적으로 권장

### Q3. 웹서비스 유료화 — 접근권한/복제방지/체험기간 (순수 웹서비스 기준)

| 원 질문 | 웹서비스 기준 재정리 | 결론 |
|---|---|---|
| 설치키 부여 | 회원가입/로그인 계정에 결제 연동해서 유료 회원만 접근 허용 가능한가? | **가능.** 이메일 로그인 + Stripe/토스페이먼츠 등 결제대행사 연동 + DB에 유료/무료 상태 저장 + 매 요청마다 서버가 확인. "계정 자체가 라이선스" |
| 무단 복제 방지 | AI-VC 방법론(프롬프트·워크플로우 로직)을 타인이 베끼지 못하게 할 수 있나? | 서버 안 로직·API 키는 사용자 브라우저로 절대 전송 안 되므로 **로직 자체는 사실상 안전**. UI/UX 모방이나 아이디어 자체 모방은 기술로 막을 수 없음(영업비밀·약관·특허 영역) |
| 체험 기간 제한 | 가입 후 일정 기간만 무료 사용 후 자동 유료 전환 가능한가? | **가능.** 서버 DB에 가입일 저장 → N일 경과 시 제한(클라이언트 로컬 체크는 우회 쉬우므로 반드시 서버 판단). Stripe의 `trial_period_days` 등 기본 기능 활용 가능 |

**권장 아키텍처 (3가지 요구사항을 하나로 해결)**
```
[사용자 브라우저] --- 화면/입력만 담당 ---> [Dr. Brian 서버]
                                              ├─ 로그인/결제 상태 확인
                                              ├─ 트라이얼 기간 확인
                                              └─ 통과 시에만 → Anthropic API 호출 (API 키는 서버에만 존재)
```

**확인/전문가 상담 필요 사항**
- 트라이얼 남용(이메일만 바꿔 무한 재가입) 완전 차단은 불가 — 이메일/휴대폰 인증, 카드 사전등록으로 억제하는 수준. 정책 수위는 서비스 방침으로 결정 필요
- EULA·환불정책·소비자보호법 저촉 여부는 법률 검토 필요 (제가 단정할 수 없는 영역)
- 예상 유료 사용자 규모에 따른 API 원가 구조는 사업계획서에 반드시 반영 필요 (위 Q2 단가표 참고)
