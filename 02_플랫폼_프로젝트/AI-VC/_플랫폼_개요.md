## AI-VC 란

「AI-VC 바이브코딩 실전 교과서」(제1권 방법론편)에서 정의한 이름.
**A**I **V**ibe **C**oding — 비전공자가 AI(Claude)와 협업해 앱·웹서비스를 만들 때
바이브코딩의 4가지 함정을 막는 **명세 기반 개발(SDD) 방법론**이자 그것을 구현한
Claude Code 스킬.

### 한 줄 정의
> 말(요청·결정·이유)을 문서로 고정하고, 승인 게이트와 증거 기반 보고로 통제권을
> 유지하며, progress.md로 세션이 끊겨도 맥락을 잇는, GitHub Spec Kit 기반의
> 초보자용 바이브코딩 절차.

### 4가지 함정 → 4가지 규칙
| 함정 | 규칙 |
|---|---|
| 애매한 요청 → 애매한 결과 | 명세(Specify) 없이 구현 금지 |
| 검증 수단의 부재 | 테스트 없이 "완성" 금지 — RED→GREEN→REFACTOR + 실행 증거 |
| 기록의 부재 | 결정을 spec/plan/tasks + 커밋에 기록 |
| 세션이 끊기면 맥락 소실 | `docs/progress.md` 세션 간 인계 (v1.2.0) |

### 7단계 (5블록)
`헌장 → 명세 → 명확화 → 계획★승인 → 작업분해★승인 → 분석 → 구현(TDD)`
(A코스: GitHub Spec Kit `/speckit.*` 활용 / B코스: 스킬 내장 경량 워크플로 — 기본값)

## 배포 / 설치

- 플러그인: `/plugin marketplace add pinusian/vibecoding-guide` → `/plugin install vibecoding-guide@vibecoding-marketplace`
- 프로젝트 동봉: `plugins/vibecoding-guide/skills/vibecoding-guide/` 를 `.claude/skills/` 아래 복사 (claude.ai/code 클라우드에서도 작동)
- 개인 스킬: `skill_최신본\install.bat` 실행 → `~\.claude\skills\vibecoding-guide\` 에 반영
- 현재 이 PC에 개인 스킬로 설치됨 (`vibecoding-guide`, v1.2.0)
